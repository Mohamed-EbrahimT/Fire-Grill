🔥 FireGrill Restaurant — Frontend

Welcome to the FireGrill Restaurant frontend project!
This is a modern, responsive web interface designed to showcase the restaurant’s menu, ambience, and brand identity with a warm, fire-themed aesthetic.

📌 Overview

This frontend provides visitors with an engaging first impression of FireGrill Restaurant. It highlights the restaurant’s signature fire-grilled dishes, atmosphere, and services through an intuitive and visually appealing layout.

✨ Features

Fully Responsive Design — Works seamlessly across desktop, tablet, and mobile.

Hero Section — Eye-catching landing section with restaurant tagline and call-to-action.

Menu Showcase — Features top fire-grilled dishes with images and pricing.

About Section — Introduces the restaurant’s story, cooking style, and values.

Reservation Button — Prominent CTA to encourage table bookings.

Contact & Location Info — Includes phone, address, and operating hours.

Smooth Navigation — Sticky navbar and section-based scrolling.
